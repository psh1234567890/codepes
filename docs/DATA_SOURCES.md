# 데이터 출처와 검증 정책

## 원칙

CodePes는 대회 검색을 돕는 디렉터리이며 참가 접수 기관이 아닙니다. 모든 일정, 자격, 규칙은 참가 전에 주최 기관의 공식 페이지에서 다시 확인해야 합니다.

데이터는 다음 우선순위로 다룹니다.

1. 주최 기관의 공식 API
2. 주최 기관의 공식 대회 페이지
3. 공식 URL이 포함된 사용자 제보를 검토한 뒤 수동 반영

블로그, 커뮤니티 글, 검색 결과 요약만으로는 자동 게시하지 않습니다.

## Codeforces

- 출처: 공식 `contest.list` API
- 엔드포인트: `https://codeforces.com/api/contest.list?gym=false`
- 범위: `phase`가 `BEFORE`이고 현재부터 180일 안에 시작하는 대회
- 갱신 주기: GitHub Actions 기준 6시간
- 게시 방식: 검증 후 자동 게시

Codeforces API 응답에는 CodePes가 공통 필드로 사용하는 별도의 “참가 신청 마감”이 없습니다. 따라서 Codeforces 항목은 다음과 같이 처리합니다.

- `applicationDeadline`: 대회 시작 시각
- `deadlineKind`: `start`
- 캘린더 제목: 신청 마감이 아니라 대회 시작임을 표시

Codeforces의 시작 시각은 API의 Unix timestamp를 ISO 8601 UTC 시각으로 변환합니다. 실제 시작 전 공식 대회 페이지에서 다시 확인해야 합니다.

API 요청이 일시적으로 실패하면 이전 생성 데이터 중 아직 시작하지 않은 Codeforces 항목을 유지합니다. 이때 실패한 시각을 검증 시각으로 덮어쓰지 않습니다. 내용이 바뀌지 않은 항목도 기존 `lastVerifiedAt`을 유지합니다.

## AtCoder

- 출처: 공식 `Upcoming Contests` 표
- 엔드포인트: `https://atcoder.jp/contests/`
- 범위: 현재부터 180일 안에 시작하는 공식 예정 대회
- 제외: 별도 영역의 `Daily Contests`
- 게시 방식: HTML 구조와 날짜·기간 검증 후 자동 게시

AtCoder도 별도의 사전 신청 마감이 없으므로 `applicationDeadline`과
`deadlineKind`를 각각 대회 시작 시각과 `start`로 기록합니다. 표의 시작 시각은
UTC로 변환하고, 기간을 더해 종료 시각을 계산합니다.

## CodeChef

- 출처: 공식 대회 목록 JSON
- 엔드포인트: `https://www.codechef.com/api/list/contests/all`
- 범위: `future_contests` 중 현재부터 180일 안에 시작하는 대회
- 게시 방식: 날짜·기간·공식 URL 검증 후 자동 게시

CodeChef 항목 역시 대회 시작 시각을 일정 기준으로 사용합니다. Division과
세부 참가 조건은 각 공식 대회 페이지에서 다시 확인해야 합니다.

## 국내 공식 알고리즘 대회

### 한국정보올림피아드

- 출처: [한국정보올림피아드 공식 안내](https://koi.or.kr/)
- 범위: 공식 메인 페이지에 연결된 해당 연도 1차·2차 대회 안내
- 게시 조건: 접수 마감, 개최 시작·종료 시각, 온라인·오프라인 방식이 모두 확인되고 접수 마감 전인 회차
- 게시 방식: 공식 회차 안내의 구조와 날짜를 검증한 뒤 자동 게시

메인 페이지에서 연도와 회차별 공식 안내 링크를 찾고 각 안내의 접수·개최
일정을 따로 읽습니다. 2차 대회처럼 전 단계 성적에 따른 자격이 있는 경우
그 자격을 단순화하지 않고 공식 안내 확인이 필요하다고 표시합니다.

### 한국정보기술진흥원 청소년 IT경시대회

- 출처: [한국정보기술진흥원 공지](https://kitpa.org/notice?page=1), [공식 지난 대회 목록](https://kitpa.org/contest/past)
- 범위: 상·하반기 연 2회 열리는 청소년 IT경시대회의 현재 공지와 회차 상세
- 게시 조건: 추가 접수 마감과 부문별 시험 시간이 있고 온라인 수험장이 명시된 접수 중 회차
- 게시 방식: 정확한 날짜·시간·온라인 진행을 검증한 뒤 자동 게시

지난 대회 목록에 아직 들어가지 않은 예정 회차를 놓치지 않도록 `/notice/`의
현재 공지와 `/contest/`의 회차 상세를 모두 찾습니다. 2025년에는 3월 제4회와
9월 제5회가 열렸고, 2026년에도 3월 제6회에 이어 9월 제7회가 공지되어
상·하반기 회차를 각각 수집할 수 있게 했습니다.

여러 시험 부문의 시작과 종료 시간이 다르면 가장 이른 시험 시작부터 가장
늦은 시험 종료까지를 행사 기간으로 기록합니다. 실제 신청 시에는 출생연도,
재학·진학 상태, 응시 부문별 자격을 공식 요강에서 다시 확인해야 합니다.

### 국민대학교 알고리즘 대회

- 출처: [국민대학교 소프트웨어융합대학 공식 안내](https://software.kookmin.ac.kr/software/biz/algorism.do)
- 범위: 같은 주소에서 매년 갱신되는 최신 회차
- 게시 조건: 지원서 마감과 대회 시작·종료 시각이 모두 확인되고 접수 중인 회차
- 게시 방식: 공식 일정 표와 대면 진행 여부를 검증한 뒤 자동 게시

고등학교 재학생·졸업생 등 공식 페이지의 참가 자격을 청소년 대상으로
분류하되, 동등 학력 인정과 같은 세부 조건은 임의 해석하지 않습니다.

### UCPC

- 출처: [UCPC 공식 연합 페이지](https://ucpc.me/)
- 범위: 공식 연합 페이지에서 연결되는 최신 연도 대회와 온라인 예선 안내
- 게시 조건: 참가 신청 마감과 온라인 예선 시작·종료 시각이 모두 확인되고 접수 중인 회차
- 게시 방식: 최신 연도 주소와 공식 주최 문구를 확인한 뒤 자동 게시

UCPC는 학·석사과정 재·휴학생과 수료생이 3인 팀으로 참가하는 대회입니다.
졸업생 제외 등 세부 자격은 공식 안내 확인이 필요하다고 표시합니다. 접수가
끝난 연도는 공식 페이지 감시는 계속하지만 사용자 대회 목록에는 남기지
않습니다.

### ICPC Korea

- 출처: [ICPC Korea 공식 페이지](https://icpckorea.org/)
- 상태: 감시 중, 자동 게시 보류
- 이유: 대회 날짜는 공개됐지만 정확한 접수 마감, 예선 진행 방식, 시작·종료 시각이 모두 확인되지 않음

공식 정보가 추가되면 수집 규칙을 검증한 뒤 자동 게시로 전환합니다. 날짜만
있는 상태에서 임의의 마감 시각이나 행사 시간을 만들어 게시하지 않습니다.

## Devpost

- 출처: Devpost 공개 해커톤 목록, 각 해커톤의 공식 일정과 규정 페이지
- 목록 범위: 공개 상태의 마감 임박순 최대 40개
- 날짜 기준: 공식 일정 표의 `Submissions` 시작·종료 ISO 시각
- 참가 범위: 표시 위치에 `Online`이 있고 공식 규정에서 대한민국 또는 전 세계 참가 가능성을 확인한 항목
- 제외: 오프라인 전용, 초대 전용, 정확한 제출 시각이 없는 항목, 국가 참가 가능성을 확인할 수 없는 항목
- 게시 방식: 목록·일정·공식 규정이 모두 검증될 때 자동 게시

Devpost 대회는 연령, 국가, 거주지, 팀 구성 같은 세부 제한이 서로 다릅니다.
규정에 `worldwide`, `all countries`, 대한민국 참가 가능, 제재 국가 외 참가
가능처럼 긍정적인 근거가 있을 때만 게시합니다. 참가 자격은 계속 `대회별
확인`으로 표시하며, 연령·직업·팀 구성 등은 공식 규정을 읽어야 합니다.
일정이나 규정 확인이 일시적으로 실패하면 이전에 같은 기준으로 검증된 유효
항목만 유지합니다.

## CTFtime

- 출처: CTFtime 공개 이벤트 API
- 엔드포인트: `https://ctftime.org/api/v1/events/`
- 범위: 현재부터 120일 안에 시작하며 `Online`·`Open`으로 명시된 가까운 일정 최대 30개
- 날짜 기준: API의 CTF 시작·종료 ISO 시각
- 게시 방식: 날짜·공식 CTFtime URL·주최자·제한 조건 검증 후 자동 게시
- 제외: 제목에 취소 또는 연기 상태가 명시된 항목

CTFtime 항목은 별도 참가 신청 마감이 아니라 CTF 시작 시각을 일정 기준으로
사용합니다. 오프라인, Academic, High-school, Prequalified, Invited only 등
한국 사용자의 원격 참가를 보장하기 어려운 항목은 자동 게시하지 않습니다.
CodePes는 CTFtime의 전체 기능이나 기록을 복제하지 않으며, 가까운 일정과
원문 링크만 제공합니다.

## itch.io Game Jams

- 출처: itch.io 공식 `Upcoming Game Jams` 페이지
- 엔드포인트: `https://itch.io/jams/upcoming`
- 상태: 자동 게시 보류
- 이유: 공개 목록만으로 대한민국 참가 가능 여부를 구조적으로 판정할 수 없음

게임잼은 대부분 온라인이지만 국가·지역·학교 제한을 일관된 필드로 제공하지
않습니다. “한국인이 온라인 참가 가능한 대회만”이라는 정책을 지키기 위해
국가 참가 가능성을 검증할 방법이 마련되기 전까지 수집기는 보존하되 게시하지
않습니다.

## DACON과 DAKER

현재 검증된 공개 대회 목록 API가 없기 때문에 공식 페이지를 사람이 확인한 항목만 `data/manual-contests.json`에 반영합니다.

수동 항목 검토 시 확인하는 정보:

- 대회 제목과 주최 기관
- 공식 페이지 URL
- 참가 신청 마감과 행사 기간
- 참가 자격과 팀 크기
- 온라인, 오프라인, 혼합 진행 여부
- `lastVerifiedAt`에 기록할 실제 확인 시각

공식 페이지가 변경되거나 모호하면 자동 추측하지 않고 보류합니다.

## 데이터 생성 과정

`npm run sync`는 다음 순서로 데이터를 만듭니다.

1. `data/sources.json`에서 활성화된 자동 출처를 읽습니다.
2. `data/manual-contests.json`의 수동 검증 항목을 스키마 검사합니다.
3. 국내 공식 대회 감시 출처와 Codeforces, AtCoder, CodeChef, Devpost, CTFtime에서 기준에 맞는 예정 대회를 가져옵니다.
4. 출처별 응답을 공통 스키마로 변환하고 날짜·URL을 검사합니다.
5. 정규화한 URL과 제목·날짜 조합으로 중복을 제거합니다.
6. 이미 기준 시각이 지난 항목을 제외합니다.
7. 결과를 다시 검증해 `src/data/competitions.generated.json`에 기록합니다.

생성 파일은 직접 편집하지 않습니다. 자동 출처 설정 또는 수동 원본을 수정한 뒤 동기화 명령을 실행합니다.

## 브라우저 전달과 fallback

배포 번들에는 생성 시점의 대회 JSON이 포함됩니다. 브라우저는 앱 시작 시 GitHub `main` 브랜치의 원격 JSON도 요청합니다.

원격 데이터는 다음 조건을 모두 통과할 때만 사용합니다.

- 필요한 필드와 값의 형식이 런타임 스키마 검증을 통과함
- URL이 HTTP 또는 HTTPS 형식임
- `updatedAt`이 번들 데이터보다 같거나 최신임

요청 실패, 시간 초과, 잘못된 스키마, 오래된 데이터 중 하나라도 발생하면 번들 데이터를 사용합니다. 이 구조는 정기 데이터 갱신을 빠르게 전달하면서도 앱이 빈 화면이 되는 것을 막습니다.

## 중복과 만료

- URL 비교 시 fragment와 불필요한 표현 차이를 정규화합니다.
- URL이 달라도 정규화한 제목과 날짜가 같으면 중복 후보로 처리합니다.
- `applicationDeadline`이 현재 시각보다 지난 항목은 목록에서 제외합니다.
- 동일 대회의 예선과 본선처럼 실제로 다른 일정은 공식 페이지 근거와 고유 ID로 구분합니다.

## 정정 요청

화면의 “대회 제보·정보 수정” 기능은 공식 URL과 설명을 미리 채운 GitHub 이슈 작성 화면을 엽니다. 이 입력은 CodePes 서버에 저장되지 않습니다. 유지관리자는 공식 원문을 확인한 뒤 반영하며, 제보만으로 자동 게시하지 않습니다.

## 알려진 한계

- Codeforces 일정은 신청 마감이 아니라 시작 시각입니다.
- AtCoder와 CodeChef 일정도 신청 마감이 아니라 시작 시각입니다.
- Devpost는 한국의 국가 참가 가능성을 확인해도 연령·직업·팀 구성 제한이 남을 수 있습니다.
- CTFtime 일정은 신청 마감이 아니라 CTF 시작 시각이며 `Online`·`Open` 항목만 제공합니다.
- 국내 공식 대회는 정확한 접수 마감과 개최 시간을 모두 확인할 수 있을 때만 자동 게시합니다.
- ICPC Korea는 일부 일정만 공개된 상태라 현재 감시만 하고 자동 게시하지 않습니다.
- itch.io 게임잼은 국가 참가 가능성을 검증할 수 없어 현재 자동 게시하지 않습니다.
- Kaggle 공식 목록 API는 인증이 필요해 현재 자동 수집 대상에서 제외합니다.
- 수동 출처는 공식 페이지 변경과 실제 반영 사이에 지연이 생길 수 있습니다.
- 주최 기관이 공지 없이 일정을 변경하거나 페이지를 삭제할 수 있습니다.
- 자격 조건의 세부 예외와 법적 해석을 CodePes가 보증하지 않습니다.
- 목록에 없다는 사실이 해당 대회가 존재하지 않음을 의미하지 않습니다.
