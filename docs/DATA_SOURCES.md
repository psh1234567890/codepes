# 데이터 출처와 검증 정책

## 원칙

CodePes는 대회 검색을 돕는 디렉터리이며 참가 접수 기관이 아닙니다. 모든 일정, 자격, 규칙은 참가 전에 주최 기관의 공식 페이지에서 다시 확인해야 합니다.

데이터는 다음 우선순위로 다룹니다.

1. 주최 기관의 공식 API
2. 주최 기관의 공식 대회 페이지
3. 공식 URL이 포함된 사용자 제보를 검토한 뒤 수동 반영

블로그, 커뮤니티 글, 검색 결과 요약만으로는 자동 게시하지 않습니다.

## Codeforces

- 출처: 공식 `contest.list` API
- 엔드포인트: `https://codeforces.com/api/contest.list?gym=false`
- 범위: `phase`가 `BEFORE`이고 현재부터 180일 안에 시작하는 대회
- 갱신 주기: GitHub Actions 기준 30분
- 게시 방식: 검증 후 자동 게시

Codeforces API 응답에는 CodePes가 공통 필드로 사용하는 별도의 “참가 신청 마감”이 없습니다. 따라서 Codeforces 항목은 다음과 같이 처리합니다.

- `applicationDeadline`: 대회 시작 시각
- `deadlineKind`: `start`
- 캘린더 제목: 신청 마감이 아니라 대회 시작임을 표시

Codeforces의 시작 시각은 API의 Unix timestamp를 ISO 8601 UTC 시각으로 변환합니다. 실제 시작 전 공식 대회 페이지에서 다시 확인해야 합니다.

API 요청이 일시적으로 실패하면 이전 생성 데이터 중 아직 시작하지 않은 Codeforces 항목을 유지합니다. 이때 실패한 시각을 검증 시각으로 덮어쓰지 않습니다. 내용이 바뀌지 않은 항목도 기존 `lastVerifiedAt`을 유지합니다.

## DACON과 DAKER

현재 검증된 공개 대회 목록 API가 없기 때문에 공식 페이지를 사람이 확인한 항목만 `data/manual-contests.json`에 반영합니다.

수동 항목 검토 시 확인하는 정보:

- 대회 제목과 주최 기관
- 공식 페이지 URL
- 참가 신청 마감과 행사 기간
- 참가 자격과 팀 크기
- 온라인, 오프라인, 혼합 진행 여부
- `lastVerifiedAt`에 기록할 실제 확인 시각

공식 페이지가 변경되거나 모호하면 자동 추측하지 않고 보류합니다.

## 데이터 생성 과정

`npm run sync`는 다음 순서로 데이터를 만듭니다.

1. `data/sources.json`에서 활성화된 자동 출처를 읽습니다.
2. `data/manual-contests.json`의 수동 검증 항목을 스키마 검사합니다.
3. Codeforces 공식 API에서 예정 대회를 가져옵니다.
4. 정규화한 URL과 제목·날짜 조합으로 중복을 제거합니다.
5. 이미 기준 시각이 지난 항목을 제외합니다.
6. 결과를 다시 검증해 `src/data/competitions.generated.json`에 기록합니다.

생성 파일은 직접 편집하지 않습니다. 자동 출처 설정 또는 수동 원본을 수정한 뒤 동기화 명령을 실행합니다.

## 브라우저 전달과 fallback

배포 번들에는 생성 시점의 대회 JSON이 포함됩니다. 브라우저는 앱 시작 시 GitHub `main` 브랜치의 원격 JSON도 요청합니다.

원격 데이터는 다음 조건을 모두 통과할 때만 사용합니다.

- 필요한 필드와 값의 형식이 런타임 스키마 검증을 통과함
- URL이 HTTP 또는 HTTPS 형식임
- `updatedAt`이 번들 데이터보다 같거나 최신임

요청 실패, 시간 초과, 잘못된 스키마, 오래된 데이터 중 하나라도 발생하면 번들 데이터를 사용합니다. 이 구조는 정기 데이터 갱신을 빠르게 전달하면서도 앱이 빈 화면이 되는 것을 막습니다.

## 중복과 만료

- URL 비교 시 fragment와 불필요한 표현 차이를 정규화합니다.
- URL이 달라도 정규화한 제목과 날짜가 같으면 중복 후보로 처리합니다.
- `applicationDeadline`이 현재 시각보다 지난 항목은 목록에서 제외합니다.
- 동일 대회의 예선과 본선처럼 실제로 다른 일정은 공식 페이지 근거와 고유 ID로 구분합니다.

## 정정 요청

화면의 “대회 제보·정보 수정” 기능은 공식 URL과 설명을 미리 채운 GitHub 이슈 작성 화면을 엽니다. 이 입력은 CodePes 서버에 저장되지 않습니다. 유지관리자는 공식 원문을 확인한 뒤 반영하며, 제보만으로 자동 게시하지 않습니다.

## 알려진 한계

- Codeforces 일정은 신청 마감이 아니라 시작 시각입니다.
- 수동 출처는 공식 페이지 변경과 실제 반영 사이에 지연이 생길 수 있습니다.
- 주최 기관이 공지 없이 일정을 변경하거나 페이지를 삭제할 수 있습니다.
- 자격 조건의 세부 예외와 법적 해석을 CodePes가 보증하지 않습니다.
- 목록에 없다는 사실이 해당 대회가 존재하지 않음을 의미하지 않습니다.
